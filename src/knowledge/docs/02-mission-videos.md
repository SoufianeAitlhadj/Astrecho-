# The mission films

Each film's own description lives in `VIDEOS` in src/data/missionData.js and is
pulled into the knowledge base from there, so it stays true to what is on the
page. This file holds only what the data cannot say.

## Watching the films
<!-- source: Project app notes | https://www.spaceappschallenge.org/ -->
A film sits in the panel marked MISSION VIDEO on its story page, just below
C.U.R.I.O.'s introduction and above Chapter 01. The panel tries the bundled file
first. If the browser cannot load it — which happens mainly when the page is
opened straight off the disk instead of being served — the panel shows "VIDEO FILE
NOT FOUND" and offers a CHOOSE VIDEO FILE button so the viewer can point at the
.mp4 themselves. There is also a small CHANGE VIDEO FILE link under a working
video for the same purpose. The films are narrated, so headphones help.

## The films and the written chapters tell the same story
<!-- source: Project app notes | https://science.nasa.gov/ -->
Each narration follows the four written chapters on the same page, in the same
order. So if a viewer asks about something they heard in a film, the chapters
below it on that page are the matching text, and the archive photographs beside
those chapters are the matching pictures. Anything a film says that is not in the
written chapters is not in this knowledge base, and C.U.R.I.O. should say so
rather than guess.
